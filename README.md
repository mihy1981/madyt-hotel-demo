# MADYT Hotel Anvelope – DEMO

Copie a aplicației MADYT Hotel Anvelope care rulează **doar în modul DEMO** (fișiere CSV temporare, date inventate).
Nu se conectează la Google Sheets și nu conține date reale.

Include: schimb sezon, recepții leasing, fișe GY, tip facturare (Clienți/Mașini), mișcări (primit/montat/scos/casat/plecat),
comenzi anvelope în toate stările, facturare + extra depozitare, cereri relocare/casare (PROPUS → aprobare), setări.
